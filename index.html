Capabilities

Everything in one package

Built on Reticulum Network Stack — cryptography-first networking designed for unreliable, low-bandwidth links.

📡
LoRa Mesh
Connect RNode devices via USB or WiFi. Long-range encrypted radio — no infrastructure, no license required.
🏠
Home Assistant Bridge
Send commands to HA over LoRa radio. Trigger automations from anywhere — even completely off-grid.
🔒
I2P Anonymous Network
Link two gateways anonymously without public IP. One-click tunnel setup from the dashboard.
🌐
Nomadnet Node
Host pages on the Reticulum network. Built-in browser, multi-page editor, Python scripts with cron scheduler.
⚙️
Web Dashboard
Full management UI on port 8081. Service control, live logs, config editor, version updates. No SSH required.
🤖
LXMF Bot
Built-in bot with /ping, /status, /info commands. Extensible — add your own handlers via MQTT automations.
